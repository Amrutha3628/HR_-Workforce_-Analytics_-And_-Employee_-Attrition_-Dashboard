# HR Workforce Analytics and Employee Attrition Dashboard

## 📊 Project Overview

An interactive **HR Analytics Dashboard** developed using **Microsoft Excel and Power BI** to analyze workforce data, employee attrition, performance, attendance, leave, training, compensation, and job satisfaction.

## 🎯 Objective

To transform raw HR data into meaningful insights that help understand workforce trends, identify attrition patterns, and support data-driven HR decision-making.

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- Power Query
- DAX
- VLOOKUP
- Pivot Tables & Charts

## 📌 Project Phases

### Phase 1 – Excel

- Data cleaning and transformation
- Duplicate removal
- Missing value handling
- Data standardization
- VLOOKUP
- Pivot Tables and Charts

### Phase 2 – Power BI

- Power Query transformations
- Data modelling
- DAX measures and calculated columns
- Interactive dashboards
- Slicers and navigation
- Drill-down and drill-through analysis
- Insights and recommendations

## 📊 Dashboard Pages

1. HR Overview
2. Employee & Department Analysis
3. Attendance, Leave & Training Analysis
4. Attrition & Performance Analysis
5. Insights & Recommendations
6.  Employee Details – Drill-through

## 📈 Key Metrics

- Total Employees
- Attrition Rate
- Average Monthly Salary
- Average Performance Rating
- Average Attendance
- Average Job Satisfaction
- Average Leave Days
- Average Training Hours
- Overtime Rate

## 🔍 Key Insights

The dashboard helps identify patterns related to employee attrition, department-wise workforce distribution, performance, job satisfaction, attendance, training, promotion, and compensation.

## 🎯 Outcome

This project demonstrates how **Excel and Power BI** can be used to clean, transform, model, analyze, and visualize HR data to generate actionable business insights.

**Data Cleaning • Excel • VLOOKUP • Pivot Tables • Power BI • Power Query • Data Modeling • DAX • Data Visualization • Dashboard Development • HR Analytics**
